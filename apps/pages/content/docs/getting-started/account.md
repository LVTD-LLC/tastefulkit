# Set up your account

Browse the full library and open design details without signing in. A free account lets you save references, build personal rankings, and connect an agent with your personal API key. Reading these docs does not require an account.

## Sign up and confirm your email

1. Choose **get started** or open the [signup page](/accounts/signup/).
2. Complete the signup form.
3. Follow the confirmation link sent to your email address.
4. [Sign in](/accounts/login/) and open [Explore](/explore/).

If the message has not arrived, check your spam folder and the address you entered. Use the confirmation reminder in your account to request another email.

## Manage sign-in details

Open **Account** from the library, or go to [Settings](/settings).

- **Change email** lets you add and confirm a new address before using it as your sign-in email.
- Use the password controls to set or change your password. If you cannot sign in, use the password-reset link on the sign-in page.
- After confirming your email, use **Add passkey** to set up a passkey on a supported device or browser. Existing passkeys can be managed from the same page.

## Generate a key for a script or agent

Your account receives an API key automatically. Sign in and choose **Copy AI Tooling Installation Prompt** on the [How to Use guide](/how-to-use/) to copy a prompt with your key already included. Keep this prompt private and share it only with an agent you trust.

Choose **Rotate key** if you need a replacement. Rotation invalidates the old key, so update any scripts or agents that used it.

Keep keys out of shared screenshots, public code, and URLs. The [API introduction](/docs/api-reference/introduction/) explains how to send a key with a request.
