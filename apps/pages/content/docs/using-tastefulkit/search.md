# Search for the design you have in mind

In [Explore](/explore/), enter a description and choose **Find inspiration ↗**. Start with a few useful words, such as `minimal`, `bold typography`, or `warm landing page`.

## Combine a description with filters

- **Element** narrows the type of reference, such as a landing page, pricing page, hero, or dashboard.
- **Style** selects a tag used in the library.
- **Industry** narrows the industry recorded for a design.

Choose your filters, then submit with **Find inspiration ↗**. Filters combine: a design must satisfy all selected filters. Style and Industry options depend on the examples currently in the library.

**Reset filters** clears the description and selected filters. In the Saved tab it keeps you within your saved designs.

## Understand the result label

- **Newest first** means no search description is being used.
- **Text + related designs** means the search can include designs related to your description, alongside literal matches.
- **Text matches** means the results use matching words in the catalogue. Search still works this way if related-design search is temporarily unavailable.

Results are references to browse, not generated designs. Try a different description when the first results do not match what you meant.

## Get better results

1. Start broad: `minimal` is a useful first pass.
2. Add one distinguishing quality, such as `bold typography` or `warm colors`.
3. Narrow the element type if you need a specific part of a website.
4. Open promising results and follow their style tags.

If nothing matches, remove a filter or shorten the description. An empty result does not mean the search is broken; the library may not yet contain that combination. Check whether you are in **Saved** if you expected to search the full library.
