# Social card font

`Inter.ttf` is the unmodified variable Inter font (`Inter[opsz,wght].ttf`) from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), retrieved
2026-09-20. It is bundled so Pillow renders social images consistently without
system fonts or runtime network requests. The renderer uses optical size 14 and
weights 400–700. See `Inter-OFL.txt` for the copyright notice and license.
