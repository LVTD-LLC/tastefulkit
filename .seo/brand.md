# TastefulKit — brand and public claim guidance

Derived from the shipped repository and public product documentation on 2026-09-12. Revisit when the product changes.

## Positioning and audience
TastefulKit is a searchable library of real website design references for people planning a website and agents helping build it. It offers visual references, not downloadable website templates or licensed source assets.

## Voice
Concrete, warm, short and visually literate. Explain what a visitor can do: search, inspect, save, and give an agent examples. Preserve the existing expressive homepage and DESIGN.md. Do not invent testimonials, catalogue scale, measured outcomes or competitive superiority.

## Shipped claims
- Search existing designs by description and filters; save a personal shortlist.
- Public documentation is readable without an account. The library and account features require authentication.
- REST and hosted MCP use a personal API key. Ingestion and capture retry require administrator privileges.

## Forbidden claims
Do not describe voting, Elo rankings, learned taste profiles or personalized recommendations as shipped. Do not imply screenshots grant reuse rights. Do not claim free forever, particular paid plans, privacy certifications or guaranteed search/AI visibility.
